# Fix It Shop cinematic source

The editable screenshot sequence used to assemble the original master is **not in this repository**. Only the delivered master remains:

- `/work/fix-it-shop/cinematic-showcase.mp4` — original 1600×1040, ~34s silent H.264, preserved.

Inspection of that master: it is assembled from website page stills with slow centered zooms (~2.5%) and crossfades, then fades to black. That zoom treatment is the source of the baked-in shake. It is not continuous screen-recorded footage.

`cinematic-loop.mp4` is a corrected web derivative rebuilt from locked frames taken at the start of each page hold in the master (before zoom accumulates), with restrained fades and a matching first/last frame for native looping. No stock footage and no replacement of Katie’s site.
